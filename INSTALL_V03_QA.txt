===================================

This patch keeps the original scorer for historical comparison while adding
an additional case-specific QA scorer. No paid dependencies.

Before installing:
1. Preserve your original /runs folder and the original v0.2 download.
2. Close the Ghost Shift server in PowerShell with Ctrl+C.
3. If you have made local code changes, back them up before replacing files.

Install into the SAME existing project folder where you previously saw
/demo, /ghostshift, and /tests:

1. Open the ZIP. Select its contents (not the outer ZIP/folder).
2. Copy them into your existing GhostShift-Cinematic-v02-Verified folder.
3. Let Windows MERGE folders and REPLACE files when asked.
4. Verify ghostshift/qa.py is next to ghostshift/engine.py.
5. Your existing runs/*.json should remain where they were. This ZIP does NOT
   include or overwrite a runs folder.

Check:

  py -3 audit/replay_qa_probe.py

Run new live experiment:
