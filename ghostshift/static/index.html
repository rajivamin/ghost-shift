What's being tested?
The predecessor's original prompt and conversation are not passed to the successor. Agent B receives only the saved handoff plus messages that arrived after the blackout. The experiment tests whether that boundary preserves enough evidence for a correct decision, including policy changes and prompt-injection attempts.
This is a tiny test, not a claim that an agent can perform a full-time job. Model responses may fail. Failure is interesting data, not something to hide.
